خطة العمل ⚔️

Action Plan
Phase 1

المرحلة 1: الإصلاح والتأسيس

  • تحسين تجربة العميل داخل المطعم (الخدمة – السرعة – التعامل).
  • إصلاح أي مشاكل في الطلب أو التوصيل.
  • تجهيز نظام تقييم Google (QR Code + تشجيع العملاء).
  • تطوير المنيو وإضافة (Calories & Protein).
  • تجهيز عروض الاشتراكات الأسبوعية والشهرية.
  • تحديد طريقة واضحة للرد على العملاء (WhatsApp / Calls).
  • تدريب الفريق على التعامل مع العملاء وعرض الاشتراك.
Phase 2

المرحلة 2: التحقق

  • بدء بيع الاشتراكات بدون إعلانات (من خلال العملاء الحاليين وWalk-in).
  • اختبار العروض المختلفة ومعرفة الأفضل.
  • متابعة ردود فعل العملاء وتحسين التجربة.
  • قياس عدد المهتمين مقابل عدد المشترين.
  • تحسين طريقة الرد والإقفال بناءً على النتائج.
  • الوصول إلى أول مجموعة من العملاء المشتركين.
Phase 3

المرحلة 3: التوسع

  • بدء تشغيل الإعلانات بشكل تدريجي (Google + Snapchat + Instagram).
  • التركيز على الحملات التي تحقق أفضل نتائج.
  • إعادة استهداف العملاء المهتمين.
  • تحسين تكلفة الحصول على العميل (CAC).
  • زيادة عدد الاشتراكات بشكل مستمر.
  • التوسع في الوصول إلى مناطق جديدة أو شرائح أكبر.

Action Plan ⚔️

Execution Roadmap
Phase 1

Phase 1: Fix & Setup

  • Improve customer experience inside the restaurant (Service – Speed – Interaction).
  • Fix any issues in ordering or delivery.
  • Set up the Google review system (QR Code + encouraging customers).
  • Develop the menu to add (Calories & Protein).
  • Prepare weekly and monthly subscription offers.
  • Define a clear method for responding to customers (WhatsApp / Calls).
  • Train the team on handling customers and pitching subscriptions.
Phase 2

Phase 2: Validation

  • Start selling subscriptions without ads (through current and walk-in customers).
  • Test different offers to see what works best.
  • Monitor customer feedback and improve the experience.
  • Measure the number of interested prospects vs. actual buyers.
  • Improve response and closing methods based on results.
  • Reach the first group of subscribed customers.
Phase 3

Phase 3: Scale

  • Gradually launch ads (Google + Snapchat + Instagram).
  • Focus on campaigns that deliver the best results.
  • Retarget interested customers.
  • Improve Customer Acquisition Cost (CAC).
  • Continuously increase the number of subscriptions.
  • Expand reach to new areas or larger segments.
